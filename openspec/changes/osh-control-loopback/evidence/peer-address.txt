Client address that a server sees, measured on 2026-10-15 on the machine that runs the app.
The machine has the LAN address 192.168.51.192. The default Docker bridge has the gateway 172.17.0.1.

Probe program (stored as text; it listens on port 8099 in the container, answers two requests and writes the address of each client to /out/peers.txt):
import socket, sys
s = socket.socket(); s.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
s.bind(("0.0.0.0", 8099)); s.listen(5)
for _ in range(2):
    c, a = s.accept(); c.recv(100); c.sendall(b"HTTP/1.0 200 OK\r\nContent-Length: 0\r\n\r\n"); c.close()
    open("/out/peers.txt","a").write("peer %s\n" % a[0])

Commands (the image is the listener image gods-eye-view-reticulum:local, which has Python; no request left this machine):
1. Bridge network with a published port, as in compose.yaml:
   docker run -d --rm -p 18099:8099 -v <probe>:/p.py:ro -v <out>:/out --entrypoint python gods-eye-view-reticulum:local /p.py
   curl http://127.0.0.1:18099/   gave the client address 172.17.0.1
   curl http://192.168.51.192:18099/   gave the client address 192.168.51.192
2. Host network, as in compose.codex.yaml:
   docker run -d --rm --network host -v <probe>:/p.py:ro -v <out>:/out --entrypoint python gods-eye-view-reticulum:local /p.py
   curl http://127.0.0.1:8099/   gave the client address 127.0.0.1
   curl http://192.168.51.192:8099/   gave the client address 192.168.51.192

What this shows:
- With the host network, a browser on this machine that opens the app as localhost has the loopback socket address. The gate passes it.
- With the host network, the same browser that opens the app by the LAN address of this machine has the LAN address as its socket address. The gate refuses it.
- With the bridge network and a published port, a request from this machine has the gateway address 172.17.0.1, never the loopback address. The gate refuses every request. This is the Known limit `bridge`.

The probe containers were stopped after the measurement (docker ps shows only the app container and the listener container of the owner).
