Run of the burst routes in a real Vite server, with a fake upstream.
The run used the files of the commit 74fe7431. The command git diff --stat 74fe7431 HEAD -- src server build prints nothing.
The script is not in the repository. It lives in the tools folder of the lead, because a script in a change folder is a coverage gap.
The script starts a fake upstream on 127.0.0.1 and a real Vite dev server with the real plugin. The plugin gets a fetch function that sends the two Bee Maps addresses to the fake. No request leaves the container.
The key is a made-up text. The clock of the plugin is a fake clock that the script moves. So the rate limit of 3 confirms for each minute does not stop the steps.
The budget file, the ledger and the audit file are real files in a temporary folder. The script prints them at the end.
