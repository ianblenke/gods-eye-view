The script reads each .js and .mjs file of the upstream range 73aec2e6..93ea088f and finds each relative import. It prints the import when the imported file on the branch differs from the same file at upstream (git diff --name-only 93ea088f 98e44aa7).

Script (python3 -I):
    import os, re, subprocess
    def names(*args):
        return subprocess.run(['git', 'diff', '--name-only', *args], capture_output=True, text=True, check=True).stdout.split()
    fork = set(names('93ea088f', '98e44aa7'))          # files where the branch differs from upstream
    upstream = names('73aec2e6', '93ea088f')           # files of the upstream range
    pattern = re.compile(r"""(?:import|export)\s[^'"]*?from\s*['"]([^'"]+)['"]|import\(\s*['"]([^'"]+)['"]\s*\)|import\s*['"]([^'"]+)['"]""")
    for f in upstream:
        if not re.search(r'\.m?js$', f) or not os.path.exists(f):
            continue
        for m in pattern.finditer(open(f).read()):
            spec = next(g for g in m.groups() if g)
            if spec.startswith('.'):
                target = os.path.normpath(os.path.join(os.path.dirname(f), spec))
                if target in fork:
                    print(f'{f} imports {target}')
