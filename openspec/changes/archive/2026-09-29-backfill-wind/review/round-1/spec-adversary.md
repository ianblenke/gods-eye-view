Verdict: FAIL
- [ ] F1 major src/layers/wind/rendering.js:27-32 `sameWind(previous, next, previousField, nextField)` decides GPU geometry reuse by looping over three key arrays: `['model','level','units']` (line 27-28), `['runIso','validIso','forecastHour','date','hour']` on `.cycle` (line 29-30), and `['nx','ny','lo1','la1','dx','dy']` on the grid (line 31-32). The `[wind-033] GPU geometry rebuilds on changed <label>` cases in rendering.test.mjs:869-915 only ever vary `model`, `cycle.runIso`, `cycle.validIso`, `grid.lo1`, `grid.dx`, `u` and `v` between two `setField` calls (plus `level`, which is in the label list). Eight keys the code explicitly compares — `units`, `cycle.forecastHour`, `cycle.date`, `cycle.hour`, `grid.nx`, `grid.ny`, `grid.la1`, `grid.dy` — are never varied anywhere in rendering.test.mjs, gpuRendering.test.mjs or index.test.mjs; every fixture leaves them `undefined` on both sides of every comparison. Because each `if` is a single source location inside a `for` loop, V8 branch coverage counts it as 100% covered as soon as any one key in the array differs (which `model`/`level`/`runIso`/`validIso`/`lo1`/`dx` already do), so the file's 100%-branch gate passes without ever exercising these eight keys' "differs" outcome. A mutation that drops or swaps the comparison for any one of them (for example checking `next.model` twice instead of `next.units`, or omitting `forecastHour`/`date`/`hour`/`nx`/`ny`/`la1`/`dy` from their arrays) makes `sameWind` wrongly report "same wind" after a real forecast change — the renderer would then keep stale GPU flow geometry — and no test in the suite would fail. This is exactly the class of gap Rule 13 (AGENTS.md) asks authors to rule out with a named mutation; the task list's mutation for wind-033 ("Accept a changed model key as equal") only proves the `model` key. Fix: add one more `[wind-033]` case per remaining key (e.g. `units: { units: 'mph' }`, `forecastHour: { cycle: { ...original.cycle, forecastHour: 6 } }`, `date`/`hour` analogues, and `nx`/`ny`/`la1`/`dy` grid variants) so each comparison is independently load-bearing.

With PASS this would be recorded as a known limit, but since it is major it must be fixed or accepted by name before merge:
