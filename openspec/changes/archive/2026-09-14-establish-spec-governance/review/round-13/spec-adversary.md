Thus a change can add new code that no test covers to an old file, and the gates do not stop. Correction: change `branch-identity` so that it names lines, branches and functions, and changed code files as well as changed tests. The counts do not become larger, so the gate does not stop. The spec adversary checks each removed or changed test and each changed code file that has a ledger entry." Or store the location of each gap in the ledger and compare the locations.
