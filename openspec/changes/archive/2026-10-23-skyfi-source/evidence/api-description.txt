Facts that the change uses, with the document that states each fact:

- The archive search is POST https://app.skyfi.com/platform-api/archives. The
  key goes in the header "X-Skyfi-Api-Key" (1, 2).
- The field "aoi" of the body is a WKT polygon. It must be a simple convex
  polygon with at most 500 vertices. The field "pageSize" is from 1 to 100 (1, 5).
- The fields "fromDate" and "toDate" are date-times in UTC (1).
- The answer has "archives" and a "nextPage" text for the next page (1).
- Each archive has a "thumbnailUrls" object that maps a size to a URL, and a
  "tilesUrl" (1).
- The same key can place orders (1, 2). The API has no key that can only search.
- GET /platform-api/ping needs no key and does not check the key (3).
- GET /platform-api/auth/whoami returns personal data of the account (1).
- The documents give no rate limit for the archive search (1).
- The Terms of Service give a personal, non-commercial license. They forbid a
  public display, except where they allow it. They have no clause for
  thumbnails, footprints or search data.
