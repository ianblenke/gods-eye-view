History of this list. The first complete run of an earlier version caught 203 of 224 faults. The survivors showed real gaps in the tests: the records tests used no status other than available, no id of 15 characters and no id that is a number; the layer tests had no list of more than 48 interfaces and no check of the label priority and the label positions; disable and destroy did not check the labels, the guidance and the error; and the catalog test did not check the source contract and the source of the layer. Each gap has a test now.
The same run showed duplicate code: the test of the signal of the request and the test of the identity of the request gave the same result, because disable and a new update always replace the request. The code keeps the identity check only, and two faults for a replaced request replace the four faults of the duplicate.
Three faults of the share token broke the import of the module, so the file of the tests failed to load. They now change the registry and the ledger, and the test of reticulum-layer-017 fails for them.
The fault "Add the points without removing the old ones" showed that no scenario said that a second update replaces the points, so the scenario 011 has that sentence now.
Pre-reviews 1 to 3 added 8 more faults (scenario 013, the share disposition, the analyst function, the source contract, the message for a missing source and the labels on an error).
