Facts that the change uses, with the document that states each fact:

- The quick search is POST https://api.planet.com/data/v1/quick-search, with
  item_types and a filter. The query parameters _page_size and _sort give the
  page size and the order (1, 2).
- An API key goes in the header "Authorization: api-key <api_key>" (5).
- An API key gives the same access as its owner (5).
- "Thumbnail previews and Data API Quick Search requests do not use Monitoring
  Credits." (6)
- Data Activation, downloads, item tiles and basemap tiles use credits (6, 7).
- The search endpoint allows 5 requests in each second (3).
- The link "thumbnail" in the "_links" of an item gives its thumbnail, a PNG
  of 256 x 256 pixels by default. A request for a thumbnail uses the
  authentication of the API (4). The example URL of (4) has the form
  https://tiles.planet.com/data/v1/item-types/<type>/items/<id>/thumb.
- Quick searches stay available through the API for 30 days (2).
- The licensee may view Planet Data through the Platform and third-party
  applications (9).
- For more than one end user, Planet Data must not rely on caching, redirection
  or other local storage (9).
- The licensee shows a copyright notice that names Planet as the source (9).
