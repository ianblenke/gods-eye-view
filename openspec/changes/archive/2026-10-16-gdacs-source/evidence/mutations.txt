Named faults of gdacs-source (AGENTS.md rule 13). One fault changes one part of the provider or of its registration. The tests then run. The list below names the tests that failed.

Code commit: dacd6309642b3bd96b5ce37987ae001d772985b5. Both runs below ran on the files of this commit, tests included. The command git diff --stat dacd6309 HEAD -- src server build prints nothing.
Runner: 6 scratch copies of the clone run in parallel. Each copy uses the same long-lived container of the image gods-eye-view:local, with the node_modules of the image.
Each fault runs against the test file src/data/gdacsProxy.test.mjs. The command is: timeout 100 node --test --test-concurrency=4 --test-timeout=6000 --test-reporter=spec <test file>
For each fault that is not an equivalent fault, the scenario in the first column is the scenario of a test that failed. The script that wrote this file checks that.
The runner used one long-lived container, named gevfaults.

The two runs give identical lines.

Equivalent faults. The description is first and the reason follows:
- "Read the type of the report link from the field eventtype". The constant `type` is a copy of `p.eventtype`. The template text is the same.
- "Encode the type of the report link for a query". The type is FL, DR, VO or TC. Encoding changes no character of these texts.
- "Let the object test accept text and numbers". A text, a number or a boolean has none of the fields that the code reads. The code gets undefined from each field, and the next rule drops the value.
- "Set the alert level to an empty text when it is not text". The list of alert levels holds neither null nor the empty text. Both values drop the record.
- "Move the border of the event id from below 1 to at most 0". The test runs after `Number.isInteger`. A whole number is below 1 exactly when it is at most 0.
- "Move the border of the episode id from below 0 to at most -1". The test runs after `Number.isInteger`. A whole number is below 0 exactly when it is at most -1.
- "Replace the geometry object test with an optional chain on its type". A value that is not an object has no property `type`. So `geometry?.type` is undefined and not "Point", and both versions return null.
- "Read a missing coordinate list as the position 0 and 0". A missing list gives the position (0, 0). The zero rule drops that position, so both versions return null.
- "Replace the added zero of the rounding with an or-zero default". The rounding gets finite numbers only. For a finite x, `x || 0` and `x + 0` both turn -0 into 0 and keep every other number.
- "Test the longitude and latitude limits before the finite test". All three tests return null and have no side effect. A comparison of a JSON value with a number never throws. So the order changes no result.
- "Add an hour below 24 test to the real clock test". An hour of 24 or more moves the date forward. The day of the date then differs from the day of the text, and the date test fails first.
- "Use the text 0 in place of the empty text as the default fraction". Both default texts pad to "000". Number gives 0 in both versions, so the time value is the same.
- "Give the empty text in place of null for a non-text alert level". Null and the empty text are both outside the list of alert levels. The record drops in both cases.
- "Pass the finite alert score through Number". The value is already a finite number. Number of a number returns the same number, also for negative zero.
- "Test the severity data with a loose null check". A value other than null, undefined or an object has no `severityunit` property. The unit is then null, and the next line returns null.
- "Test the raw severity at least one half in place of the rounded value". Math.round(x) is the floor of x + 0.5. That floor is above 0 exactly when x is at least 0.5.
- "Change the border test of the severity value to value at most zero". The value is a rounded finite number and never NaN. So "not above 0" and "at most 0" give the same result.
- "Return an empty text in place of null for a value that is not text". Every caller tests the result with `||` or `!`. Null and the empty text act the same.
- "Join each run of one or more spaces in place of two or more". A single space is replaced by a single space. The text does not change.
- "Cut with substring in place of slice". A start of 0 and a positive whole end give the same text with `slice` and with `substring`.
- "Trim one space at the start in place of a run of spaces". The join step leaves no run of two spaces, and the cut keeps that. A space at the start is always a run of one.
- "Trim one space at the end in place of a run of spaces". The join step leaves no run of two spaces, and the cut keeps that. A space at the end is always a run of one.
- "Write the iso3 in upper case after the pattern test". The pattern test passes only three letters from A to Z. `toUpperCase` does not change such a text.
- "Test for an equal or higher episode id before the modified times". The first operand already takes every higher episode id. The second operand only sees equal or lower ids, so `>=` and `===` give the same result.
- "Compare the ids with less than or equal in the id test". The ids are the keys of the join map, so each id is unique. The sort never compares an event with itself.
- "Compare the ids with localeCompare in the id test". An id is two capital letters, a hyphen and the text of a whole number, such as FL-1e+21. For such texts `localeCompare` and `<` give the same order. The agent that wrote the fault compared 2.7 million pairs in three locales and found no difference.
- "Place the events with no modified time at the smallest safe integer". The smallest valid time is about -6e13 milliseconds, which is above -9e15. Each comparison keeps its sign. Two null times give 0 in place of NaN, and both are false in the sort test.
- "Return the records at a page that answers 204". After the loop the code only returns the records. The `finally` block runs in both cases, so `return` gives the same result as `break`.
- "Stop at a short page or at the page limit in the same test". After page 5 the `for` loop ends at once. A `break` at page 5 gives the same records as the end of the loop.
- "Reverse the joined events before the sort". The comparator is a total order: the modified time, then the unique id. It never returns 0, so the input order does not change the sorted list.
- "Pass undefined as the start of the cut of the date text". The call `slice(undefined, 10)` starts at 0 as `slice(0, 10)` does.
- "Cut the date text at the letter T in place of the tenth character". For a year from 0000 to 9999, `toISOString` gives YYYY-MM-DDTHH:MM:SS.sssZ. The text before T has ten characters. It differs only for a clock beyond the year 9999.
- "Change the text of the status error". The catch clause of refresh binds no error, so the text of the error is never read.
- "Drop the object test of the page body". A null body throws a TypeError at `body.type`, and the refresh fails. Any other value that is not an object has no type "FeatureCollection".
- "Test the features value with typeof in place of the list test". JSON gives only arrays as iterable objects. The spread of null or of a plain object throws a TypeError, and the refresh fails as before.
- "Pass a reason to the abort call of the timer". The abort reason only changes the error that `readResponseTextCapped` throws. The catch clause of refresh ignores that error.
- "Set stale on the cached document and serve that object". A refresh runs only when the cache is at least 10 minutes old. The changed object then serves only through the stale path. That path sets stale true anyway, until a good refresh replaces it. This holds while the clock does not go back.
