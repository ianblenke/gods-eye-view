Automatic mutation run of server/providers/gdacs.js. The tool is the AST mutation tool of the lead (gev-tools/automut). It changes one place of the file at a time, for example a comparison, a number, a regular expression or a statement.
The tests of src/data/gdacsProxy.test.mjs then run on each mutant, and the first failing test ends that mutant.
The named faults of mutations.txt were written by hand and by agents. This run tests the tests with a different method, and it found gaps that the named faults did not name.
