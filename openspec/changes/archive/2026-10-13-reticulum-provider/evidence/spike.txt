Listener test of 2026-10-13 (host Node-free; Python 3.14.7, rns 1.5.7, lxmf 1.2.0 in a scratch environment outside this repository).
The node ran as a client only: enable_transport = no, share_instance = no, discover_interfaces = yes. It connected out to five public entry points that the community directory directory.rns.recipes lists (the directory is named in the Reticulum README for this use). It announced nothing.
Command to read the list: rnstatus --config <dir> -d --json (it can print a log line on the same stream before the JSON; read from the first "[{").
The names and positions of the operators are NOT recorded in this repository.

From the installed Reticulum source (RNS/Discovery.py, RNS/Reticulum.py): the default announce interval of a discoverable interface is 6 hours (the smallest value is 5 minutes). An entry becomes "unknown" after 24 hours, "stale" after 3 days and is removed after 7 days.
So a short test cannot show the final count. The listener container of change 2 keeps its registry on disk.
