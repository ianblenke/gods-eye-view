Automatic mutation runs of the changed files. The tool is the AST mutation tool of the lead (gev-tools/automut). It changes one place of a file at a time, for example a comparison, a number, a regular expression or a statement.
The tests then run on each mutant, and the first failing test ends that mutant. The named faults of mutations.txt were written by agents and by hand. This method found gaps that they did not name.
