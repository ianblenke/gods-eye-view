Local run of the Bee Maps frames provider in the image gods-eye-view:local (Node v24.21.0, Vite as in the repository).
It starts a fake upstream on 127.0.0.1 and a real Vite dev server on 0.0.0.0:5199 with the plugin. The plugin gets a fetch function that sends the URL of Bee Maps to the fake upstream and throws for any other URL.
No request left the container. The key is a made-up fixture text. The container was started for this run only, with the clone mounted and the node_modules of the image. It stopped when the script ended, and docker ps afterwards listed only the two containers of the owner.
The run used the files of the commit 82d7987c. The files under server/ are the same in the commit e466de1f: the command git diff --stat 82d7987c HEAD -- server prints nothing. The script is not in the repository (a script in a change folder is a coverage gap); it lives in the tools folder of the lead and ran with: docker run --rm -i -v <clone>:/app -v /app/node_modules -w /app gods-eye-view:local node --input-type=module - < local-run.mjs

The script prints the list `frames` of an answer as a count and the first frame. The answers hold the whole list.
Requests to the route count against the rate limit (6 in 60 seconds). Steps 2, 3, 8, 9, 10 and 11 reach the rate-limit step, so the script stays under the limit. Steps 4 to 7 stop before it.
Node v24.21.0; fake upstream on 127.0.0.1:46271; Vite dev server on 0.0.0.0:5199; container address 172.17.0.2
