A fault in a file of the layer that leaves that test file green then runs against all seven test files: src/layers/beemaps/*.test.mjs. A fault in a registration file runs against src/layers/beemaps/registration.test.mjs, src/data/layerState.test.mjs, src/data/layerStateTokenLedger.test.mjs, src/app/constructCatalog.test.mjs, src/app/sourceComposition.test.mjs and src/sources/reference.test.mjs.
The second step can only add failing tests, so a fault that fails no test in both steps is a real survivor. A failure with no scenario tag is a test of the existing project or a test file that fails when it loads (the registry or the catalog is wrong), and the lines below name it.
The container ran next to the two containers of the owner and stopped when the run ended. No other container ran at the same time.
